# 11월 GWP(증정) 품목 가격 계획 누락 건

작성 2026-11-27 · 대상 11월(2026-11) DTC 가격 계획 · 품목 Music Studio(LS51H, LS71H)

---

## 1. 무엇이 일어났나

11월 2일부터 25일까지 CE 프로모션에 **Gift with Purchase**(`GWP-Music
Studio(LS51H)`)가 운영되었습니다. 해당 기간 증정품은 **금액 0원**으로 출고되었으나,
계획 가격은 통상가로 수립되어 있었습니다.

| 품목 | 계획가(GSCM) | 실현가 | 차이 |
|---|---|---|---|
| HW-LS51H/XY | 208 | **14** | −194 |
| HW-LS71H/XY | 312 | **29** | −283 |

실현가가 계획가의 **7~9% 수준**입니다. 일반적인 프로모션 할인(통상 10~50%)과는
자릿수가 다른 괴리이며, 대부분의 수량이 할인 판매가 아니라 **무상 출고**되었기
때문입니다.

## 2. 현재 가격 산정 범위

가격 산정 로직은 현재 고도화를 진행 중이며, 운영 중인 범위는 다음 두 가지입니다.

- **과거 실현 ASP 반영** — 직전 6개월 실적 단가를 기준으로 다음 달 가격을 추정
- **주요 프로모션 반영** — 프로모션 테이블에 등록된 캠페인의 할인율을 가격에 반영

이번 GWP 건은 이 두 축 어디에도 걸리지 않았습니다. 이유는 GWP가 가진 세 가지
성격 때문이며, 모두 일반적인 할인 프로모션에는 없는 특성입니다.

### 2-1. 할인이 아니라 증정

GWP는 가격을 깎는 것이 아니라 **별도 품목을 무상으로 제공**하는 행위입니다.
프로모션 테이블에서도 `Offer_Detail`에 금액(`$`)이나 비율(`%`)이 기재되지 않고
`GWP-Music Studio(LS51H)`와 같이 텍스트로만 적힙니다. **할인율 축에 올릴 값이
존재하지 않아** 프로모션 반영 로직의 입력이 되지 못합니다.

### 2-2. 증정품이 프로모션 테이블에 자기 행을 갖지 않음

GWP 라인은 **구매하는 제품**(사운드바 MRA 계열)의 행에 등록되고, 증정품은
`Offer_Detail` 본문 괄호 안에만 표기됩니다.

```
행 소유자: MRA-Q990F      Offer_Type: Gift with Purchase
                          Offer_Detail: GWP-Music Studio(LS51H)
```

가격은 SKU 단위로 산정하는데, 증정품 SKU(LS51H)로 프로모션 테이블을 조회하면
**해당 월에 등록된 프로모션이 없는 것으로 조회됩니다.**

### 2-3. 무상 출고분이 ASP 기준에 포함되지 않음

판매 원장에서 **수량은 있고 금액이 0인 라인**은 단가 계산이 불가하여 집계에서
제외해 왔습니다. 이에 따라 과거 실현 ASP는 유상 판매분 기준으로 산출되며,
증정이 있었던 기간도 ASP상으로는 통상가로 나타납니다.

추가로 이번 건은 해당 품목의 **첫 GWP 운영**으로, 과거 6개월 창에 무상 출고
이력 자체가 없었습니다.

## 3. 보완 내용

### 3-1. 무상 출고분을 실적에 포함 (구현 완료)

금액 0원 라인을 집계에 포함합니다. 마이너스 라인(반품·취소)만 제외합니다.
출고된 수량은 계획에 잡힌 수량이므로, 실현가를 **무상분 포함 출고 기준
평균단가**로 산출합니다. 실행 시 포함 건수를 로그에 표시합니다.

### 3-2. 증정품을 `Offer_Detail`에서 해석해 증정품 SKU에 귀속 (구현 완료)

GWP 라인의 괄호 안 모델명(`LS51H`)을 실제 판매 코드(`HW-LS51H/XY`)에 연결하여,
구매 제품이 아닌 **증정품**의 해당 기간을 증정일로 인식합니다. 모델명이 없는
경우 증정품 명칭을 프로모션 테이블의 제품 설명과 대조합니다.

명칭이 여러 제품에 해당하는 경우에는 **어느 것도 표시하지 않습니다.**
`Music Studio`는 LS50H·LS51H·LS70H·LS71H가 공유하는 패밀리명이므로 명칭만으로는
증정품을 특정할 수 없으며, 추정 적용 시 증정하지 않은 품목의 가격까지 왜곡됩니다.

### 3-3. 증정일 별도 기준 적용 (구현 완료)

증정일은 일반 프로모션일과 분리하여 다음 순서로 산정합니다.

1. 해당 품목의 **과거 증정일 실적** — 무상 비율을 실제 데이터에서 산출
2. 동일 그룹의 과거 증정일 실적
3. 전례가 없는 경우 **0원 기준** — 증정은 정의상 0이며, 통상가보다 정확한 추정

LS51H 기준 **10.4**로 산출됩니다(실현 14). 기존 산정으로는 86이었습니다.

> 3-1~3-3은 구현을 마쳤으며, 10월·11월 실적으로 검증 중입니다.

### 3-4. 프로모션 등록 항목 보완 (협의 필요)

시스템 보완으로 대부분 자동 처리되나, 원천 데이터에 아래 두 항목이 있으면
**추정이 아닌 확정값으로 처리**됩니다.

| 항목 | 내용 |
|---|---|
| **증정품 SKU** | `Offer_Detail` 본문이 아닌 별도 필드에 full model code 기입 |
| **증정 예상 수량** | 증정 대상 수량 또는 구매 대비 증정 비율 |

현재 괄호 표기도 읽을 수 있으나 표기 방식 변경 시 재발 가능성이 있어, 별도
필드 운영을 제안드립니다.

### 3-5. 월초 점검 절차

가격 산정 실행 시 아래 항목이 출력됩니다. **월 가격 확정 전 확인합니다.**

```
0원 출고 라인 포함 건수
GWP 라인 수 / 증정품 특정 성공 건수 (모델코드 기준 / 명칭 기준)
증정품 특정 실패 건수 (패밀리명만 기재된 경우)
```

특정 실패 건이 있으면 해당 GWP의 증정품 SKU를 수기로 확인합니다.

## 4. 남은 한계

- **무상 비율은 전례가 있어야 산출 가능합니다.** 전례가 없으면 0원으로 가정하므로,
  증정 기간에도 유상 판매 비중이 높은 품목은 과소 추정됩니다. 3-4의 증정 예상
  수량이 등록되면 해소됩니다.
- **증정품이 패밀리명으로만 기재된 경우 자동 특정이 불가합니다.** 설계상 추정하지
  않으므로 3-5의 점검에서 확인이 필요합니다.
